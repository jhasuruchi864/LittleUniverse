💌 How to Enable Live AI Image Generation

Our Couple Studio supports OpenAI DALL-E 3, Stability AI, and Google Gemini Imagen. To enable live photo generation, add your API key to the .env file on your server: 

# Open .env in your project folder and add:
OPENAI_API_KEY=sk-proj-your-openai-api-key-here
# or
STABILITY_API_KEY=sk-your-stability-api-key-here

Privacy Guarantee: All API keys stay strictly on the server and are never exposed in browser code. Reference photos are transmitted only when you click "Generate Romantic Artwork" with your explicit consent.
